# Onboarding for AI Agents

This project uses a persistent **project memory** that lives alongside the code: `docs/memory/`

Before starting any task, read in order:

1. `docs/memory/constitution.md` — non-negotiable working rules (compliance is mandatory)
2. `docs/memory/index.md` — the memory map; descend from there into the module relevant to your task

Working rules are defined only in the constitution; this file contains no project-specific rules and is identical in every project.
